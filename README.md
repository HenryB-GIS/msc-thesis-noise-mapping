# MSc Thesis — Strategic Noise Mapping

## Integrating Enhanced Building Representations into the CNOSSOS-EU Method for Strategic Noise Mapping

**Case study: Graz, Austria**

This thesis investigates whether richer building geometry derived from LiDAR and aerial imagery produces materially different CNOSSOS-EU strategic noise-mapping results compared with a strong conventional 2.5D building model.

## 30-second summary

- Compared a conventional 2.5D CNOSSOS-EU noise model with an enhanced building representation derived from high-resolution LiDAR and aerial imagery.
- Kept terrain, traffic sources, receivers and calculation settings matched so that the effect of building representation could be isolated.
- Found that richer building geometry produced mainly small broad-area changes, with larger differences rare and highly localised — highlighting how operational modelling software can limit the value of richer source data.
